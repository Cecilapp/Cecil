Ceci est le premier article du blog. Un article est un fichier Markdown stocké dans le répertoire `pages/blog/` : la section _blog_.

<!-- break -->

Le texte situé au-dessus du commentaire `<!-- break -->` est le _résumé_, affiché dans la liste des articles.

Cet article est la traduction de `welcome.md` : il a le même nom de fichier, suffixé par le code de langue (`.fr`).
