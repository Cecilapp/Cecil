---
title: Tags and dates
description: How to define the date of a post and how to classify it with tags.
tags: [Cecil, Markdown]
---
The date of this post is defined by the prefix of its file name: `2026-09-15_tags-and-dates.md`.

<!-- break -->

The date can also be defined with the `date` variable of the front matter, otherwise the file modification date is used.

Tags are defined with the `tags` variable: each tag has its own page, listing the posts tagged with it, and the list of all tags is available at [/tags/](/tags/).
