renderFindings()

FindingsTableTrait.php : 46

Renders findings grouped by page (one table per page).

protected renderFindings(OutputInterface $output, array<int, array<string, string>> $findings, array<int, array{header: string, cell: callable, ratio?: float}> $columns) : void

Each column is defined by a header, a cell callback and an optional ratio:

  • without ratio, the column is as wide as its content;
  • with a ratio, the column shares the remaining width and its content is wrapped. The cell callback receives the finding and the width to wrap to: null for horizontal tables (wrapped with the column max width), an int for vertical tables (which only indent multi-line values).

$output : OutputInterface
