Configuration merger.

Merges configuration layers (defaults, themes, site), $high taking precedence over $low.

merge()  : array<string|int, mixed>
Merges two configuration arrays, key by key: values of `$high` take precedence over values of `$low`.
mergeValues()  : mixed
Merges two values, `$high` taking precedence over `$low`: - scalars are replaced; - a boolean applied to a map enables or disables it (ie: `cache: false`), the map is kept; - lists of values are replaced as a whole, except in preserve mode (ie: theme configuration) where they are combined; - a map of booleans applied to a list of values adds (`true`) or removes (`false`) items; - lists of identified items (ie: `output.formats`) are merged by identifier; - other lists of items (ie: menus entries) are concatenated in merge mode, replaced otherwise; - maps are merged key by key.

mergeListAndMap()  : array<string|int, mixed>
Merges a list and a map: a map of booleans applied to a list of values adds (`true`) or removes (`false`) items, otherwise `$high` replaces `$low`, except an empty array (ie: `{}` in YAML) which doesn't override a map.
mergeListById()  : array<int, mixed>

mergeLists()  : array<int, mixed>
Merges two lists: - lists of identified items (ie: `output.formats`) are merged by identifier; - lists of values are replaced as a whole, except in preserve mode (ie: theme configuration) where they are combined; - other lists of items (ie: menus entries) are concatenated in merge mode, replaced otherwise.
mergeScalar()  : mixed
Merges two values, at least one of them not being an array: `$high` replaces `$low`, except a boolean applied to a map, which enables or disables it (ie: `cache: false`).
