LinksDoctor

LinksDoctor.php : 41

Links audit domain service.

Builds the site in dry-run mode, then checks the links found in the rendered HTML pages and in the linked CSS files:

  • internal links must target a generated page, a static file or an asset, and their fragment (if any) must match an element ID of the target page;
  • external links are requested over HTTP.

HTML/CSS parsing and generated files indexing are delegated to Links\LinkExtractor and Links\TargetIndex: the remaining complexity comes from the link checking rules.
