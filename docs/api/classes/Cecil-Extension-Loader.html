Loader

Loader.php : 31

Extensions loader.

Loads the extensions (generators, Twig extensions, post-processors, etc.) declared in a configuration key, as a map of entries indexed by name:

  • <name>: <class>
  • <name>: {class: <class>, priority: <int>, enabled: <bool>}
  • <name>: false (disabled)

Extensions are sorted by ascending priority (declaration order for equal priorities). An invalid extension fails the build, unless extensions.strict is disabled: the error is then logged and the extension skipped.
