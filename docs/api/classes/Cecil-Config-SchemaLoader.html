SchemaLoader

FinalYes
SchemaLoader.php : 38

Front matter schemas loader.

Loads the front matter schemas of a schemas/ directory: one YAML file per key of pages.schema (a section, or a page as returned by Schema::pageKey()), whose path relative to the directory, without its extension, is the key (schemas/blog.yml is blog, schemas/blog/index.yml is blog/index). The schema of all pages (*) is the _all.yml file. A file holds the fields of the schema directly.

Schemas layers are merged field by field: the definition of a field is replaced as a whole.
