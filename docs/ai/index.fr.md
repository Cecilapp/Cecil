# IA

Cecil prend en charge l’IA à deux niveaux :

- **Lorsque vous créez un site** : des skills d’agents apprennent aux agents de code IA (Claude Code, GitHub Copilot, Cursor, etc.) à créer, configurer et thématiser un site Cecil.
- **Lorsque votre site est publié** : Cecil peut générer un fichier `llms.txt` et des versions Markdown de vos pages, afin que les modèles de langage puissent lire votre contenu, et vous permet de contrôler les robots d’IA avec `robots.txt`.
