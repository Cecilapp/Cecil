# AI

Cecil supports AI on two sides:

- **When you build a site**: agent skills teach AI coding agents (Claude Code, GitHub Copilot, Cursor, etc.) how to create, configure and theme a Cecil site.
- **When your site is published**: Cecil can render a `llms.txt` file and Markdown versions of your pages, so language models can read your content, and lets you control AI crawlers with `robots.txt`.
